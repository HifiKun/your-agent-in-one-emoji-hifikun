A program that writes one emoji to `/output/entry.txt` — the single glyph that stands for the AI agent Hana: 🐝, the honeybee. A tireless background worker that takes a task, flies off on its own, and comes back with the result — and works the flower it serves (Hana means flower).

## Run it

```sh
python3 main.py
```
